# 人工智能与数据科学学院 课程知识图谱

中国科学技术大学人工智能与数据科学学院（人工智能、数据科学与大数据技术专业）15 门课程的知识图谱，按《专业知识图谱建设标准》建设。

- **网站**：<https://114August514.github.io/ustc-saids-kg/>
- **交付包**：[Releases](https://github.com/114August514/ustc-saids-kg/releases) 中的 `standard-<日期>.zip`，即建设标准第六章格式的数据（课程图谱、专业知识图谱、课程关系汇总表、课程知识点对齐表）及说明文档。

## 目录

| 路径 | 内容 |
|---|---|
| `说明/` | 交付文档：[数据层说明](说明/数据层说明.md)、[数据结构](说明/数据结构.md)、[建设方案说明](说明/建设方案说明.md)、[参考材料](说明/参考材料.md) |
| `docs/` | 网站（GitHub Pages 的发布目录），由交付包数据构建，请勿手工修改 |

## 网站功能

- 专业总览：15 门课按培养方案开课学期排列，课程之间的前置与关联关系。
- 课程页：章节、知识模块、知识点目录，以及知识模块前置图。
- 知识点页：定义、教材原文与页码、前置与后续、相关知识点、其他课程中的同一知识点。
- 学习路径：为一个知识模块或一门课排出按先后顺序的学习清单，可勾掉已掌握的内容。
- 课程关系分析：与培养方案的对照、课程间重复讲授的知识点、课程对的关系强度。
- 搜索：课程名、知识点名、英文名、别名、关键词。
